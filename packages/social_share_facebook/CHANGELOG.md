# Changelog

## 0.0.1

- 提供 Facebook Android Kotlin / iOS Objective-C 分享功能。
- 支持链接、单图、图片下载处理、SDK 回调以及网页兜底。
- Android 依赖 `facebook-share:12.0.0`，iOS 依赖 `FBSDKShareKit ~> 18.0` 和 `FBSDKCoreKit ~> 18.0`。
- Android 插件声明 minSdk 16，iOS 最低版本 15.6。
- 使用独立 Channel、原生类名和 FileProvider authority，导出 Core 公共 API。
- 提供配置与使用说明、公共导入入口及 Dart 接入测试。
